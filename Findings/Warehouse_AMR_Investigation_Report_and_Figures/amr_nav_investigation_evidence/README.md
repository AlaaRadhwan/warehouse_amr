# Companion evidence for the Warehouse AMR investigation

The primary technical report is `Warehouse_AMR_Terminal_Navigation_Investigation_2026-10-22.md`.

- `figures/`: the three MPPI spin/replay plots and baseline kinematic calibration plots.
- `source_reports/`: source Markdown notes and analysis reports used to compile the main report.
- `summary_data/`: baseline rotational and linear identification CSV summaries.

This is a compact report/evidence package, **not** an archive of the complete ROS bags, simulation traces, source code, or calibrated post-test raw recordings. Original project paths and reproducibility caveats are enumerated in §9 of the main report.
